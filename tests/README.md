# Project2 Tomasulo Tests

These tests are scoped to the simplified Project2 engine:
- Supported instructions: `add`, `addi`, `mul`, `lw`, `sw`, `nop`
- No branch/jump assumptions
- Stop condition remains signature write to address `100`

## Test Set

- `tomasulo01_addi_smoke.s` -> expected signature `5`
- `tomasulo02_add_chain.s` -> expected signature `21`
- `tomasulo03_mul_basic.s` -> expected signature `42`
- `tomasulo04_sw_lw_roundtrip.s` -> expected signature `33`
- `tomasulo05_dual_independent.s` -> expected signature `11`
- `tomasulo06_slot_dep.s` -> expected signature `9`
- `tomasulo07_mul_add_mix.s` -> expected signature `17`

Each `.s` file has a matching `.mem` generated by `asygen.py`.

## Regenerate Memory Images

```bash
python3 tests/asygen.py tests/tomasulo01_addi_smoke.s
python3 tests/asygen.py tests/tomasulo02_add_chain.s
python3 tests/asygen.py tests/tomasulo03_mul_basic.s
python3 tests/asygen.py tests/tomasulo04_sw_lw_roundtrip.s
python3 tests/asygen.py tests/tomasulo05_dual_independent.s
python3 tests/asygen.py tests/tomasulo06_slot_dep.s
python3 tests/asygen.py tests/tomasulo07_mul_add_mix.s
```

## ModelSim Run (Primary)

```bash
./tests/run_tomasulo_modelsim.sh tests/tomasulo01_addi_smoke.mem tomasulo01_addi_smoke
```

The runner compares `FINAL_SIGNATURE` against the expected value for known Tomasulo tests.

Optional third argument overrides the expected value:

```bash
./tests/run_tomasulo_modelsim.sh tests/tomasulo01_addi_smoke.mem tomasulo01_addi_smoke 5
```

Run the full project-specific test set:

```bash
./tests/run_tomasulo_modelsim_suite.sh
```
